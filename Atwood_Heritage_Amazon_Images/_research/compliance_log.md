# compliance_log.md (§11–§24)

Standard: current CFIA (inspection.canada.ca) + Health Canada advertising/labelling rules. Images
are food advertising; visuals are claims (§23). This log is a working record, not legal sign-off.

## Gates enforced in every prompt
- §13 FOP symbol: preserve exactly if present on the current package; presence unconfirmed per SKU → verify on label.
- §14 nutrient claims: no "High Protein/Low X" unless SKU qualifies; else raw NFt values only.
- §15 health-claim blacklist: none used.
- §16/§17 GF/DF: website states brand-wide; confirm each SKU label before showing.
- §18 allergens: never infer absence; mirror exact Contains/May Contain.
- §19 method claims (grass-fed/fermented/smoked/handmade/no fillers): substantiate per SKU.
- §20 game meat: blends (pork & beef base) — never imply 100% species.
- §21 origin wording: distinct claims; use exact package wording.
- §22 "fresh": prohibited for cured/fermented/smoked/shelf-stable.
- §23 visual accuracy: food must resemble the actual SKU; no invented ingredients/textures.
- §24 main image: white bg, product only, accurate qty, no text/props/added logos.
