# 08 — QA Checklist (Master) — Before Upload

The final gate. Copy this into each ASIN's `06_QA/qa-checklist.md` and check every box before
anything goes live. If a box can't be checked, it goes to the brand request checklist, not the listing.

---

## A. Source-of-truth verification
- [ ] `product-spec.md` complete and confirmed by brand
- [ ] Physical label images on hand (front + Nutrition Facts + ingredients + allergens, bilingual)
- [ ] Every on-image/on-copy claim mapped to a source (spec / label / official site / live listing)
- [ ] Claim→source log filled in below

## B. Images (all 9)
- [ ] 2000×2000, square, sRGB, JPEG q≥90, <10 MB each
- [ ] Named `ASIN_slotNN_shortdesc.jpg`
- [ ] **Image 1:** pure white bg, product only, ~85% fill, NO text/badge/prop
- [ ] Images 2–9 match their assigned job (`02_nine-image-layout-plan.md`)
- [ ] Consistent fonts, palette, badge style, light direction across all 9
- [ ] Each image legible at 300×300 thumbnail
- [ ] No distorted/garbled text; all spelling correct
- [ ] No fake certification logos, no watermarks, no promo text, no URLs, no competitor marks
- [ ] Nutrition/label recreations match the real panel exactly
- [ ] Product depicted matches the actual product

## C. Listing copy
- [ ] Title: brand-first, primary keyword ≤80 chars, metric net qty, ≤200 chars, no promo/superlatives
- [ ] 5 bullets, benefit-led, bolded lead-ins, fact-backed
- [ ] Description filled
- [ ] Backend keywords: no title repeats, includes FR terms, no competitor/ASIN spam
- [ ] Structured attributes complete (allergens, dietary, origin, net qty, storage)

## D. A+ Content
- [ ] Module stack built per `04_a-plus-content-plan.md`
- [ ] Meaningful copy in text fields (not baked into images)
- [ ] Comparison chart uses own range / objective attributes only
- [ ] All claims sourced; no medical/superlative claims

## E. Canada food compliance (from `07`)
- [ ] Bilingual label shown where label appears
- [ ] Nutrition numbers match NFt exactly; allergens present
- [ ] No medical/therapeutic claims; no unverified superlatives
- [ ] Nutrient/dietary/certification claims substantiated
- [ ] Origin claim verified to correct CFIA standard
- [ ] Net quantity metric & correct
- [ ] No promo text / URLs / competitor marks anywhere

## F. Consistency & brand
- [ ] Reads as "Atwood Heritage" next to other catalog ASINs
- [ ] Store/A+/gallery visually consistent

## G. Sign-off
- [ ] Claude art-direction pass complete
- [ ] Brand review complete (anything uncertain resolved)
- [ ] Approved for upload — date: ______  by: ______
