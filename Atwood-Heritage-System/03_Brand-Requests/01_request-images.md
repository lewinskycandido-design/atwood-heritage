# Category 1 — LISTING IMAGES: What We Need From You

We produce **9 gallery images per product**. Below is what each image needs and what you must send
us to create it. Provide the product-specific items **per ASIN**; the brand items **once**.

---

## The 9 images we build (so you know what the materials feed)
1. **Main image** — your product on a plain white background (Amazon requirement)
2. **Key benefit / overview** — product + top selling points
3. **Ingredient / source / quality story**
4. **Nutrition / product facts** — built from your real label
5. **Pack size / servings / how to use**
6. **Lifestyle** — your product in a real setting
7. **Brand trust / heritage story**
8. **Comparison / product range**
9. **Why choose Atwood Heritage** (closing image)

---

## A) Product PHOTOGRAPHY (per ASIN) — the most important item
Send the highest-resolution photos you have (**min 2000 px**, originals preferred):

- [ ] **Front of pack** — straight-on, clean, sharp (feeds the main image)
- [ ] **Back and side(s) of pack** — so we can read all panel info
- [ ] **Product out of the pack / contents** — the actual food (beans, granola, etc.)
- [ ] **Key raw ingredients** — e.g. oats, maple, berries, coffee cherries (feeds image 3)
- [ ] **Lifestyle / in-use shots** — product in a kitchen/table/real setting, if you have any (feeds image 6)
- [ ] **Product range / line-up** — all variants together, if available (feeds image 8)

> No professional photos? Tell us — we can work from clean phone photos of the real pack, but the
> **front-of-pack shot must be sharp and true to the actual product and label.**

## B) LABEL & NUTRITION images (per ASIN) — required for image 4
- [ ] **Front-of-pack label** (high-res)
- [ ] **Nutrition Facts panel** — the **bilingual EN/FR** table, fully legible
- [ ] **Ingredient list** (exact wording/order)
- [ ] **Allergen statement** ("Contains: …")
- [ ] **Net quantity** as printed (e.g. 500 g)

> We reproduce these exactly — we never invent or change nutrition numbers.

## C) PRODUCT FACTS to confirm in writing (per ASIN)
- [ ] Official product name + variant/flavour
- [ ] Net quantity (metric) + count per pack
- [ ] Servings per container + serving size
- [ ] Format (whole bean/ground, whole/sliced, etc.)
- [ ] How to use / prepare (steps)
- [ ] Storage conditions + shelf life
- [ ] Top 3 selling points you most want highlighted

## D) CLAIMS & CERTIFICATIONS (per ASIN) — only if you hold them
For anything you want shown as a badge/claim, send **proof + the logo file**:
- [ ] Organic / non-GMO / gluten-free / kosher / halal / other: __________
- [ ] Certificate or substantiation for each
- [ ] "Made in Canada" vs "Product of Canada" — tell us which is accurate and confirmed

## E) BRAND ASSETS (send ONCE, brand-wide)
- [ ] Logo — vector (SVG/EPS/AI) **and** transparent PNG
- [ ] Brand colours (hex or Pantone/CMYK)
- [ ] Brand fonts (files or names)
- [ ] Any brand guidelines document
- [ ] Confirmed heritage facts: founding year, family-owned?, region/origin
- [ ] Your "do-not-say" list (any wording legal/brand won't allow)
