# 03 — Listing Optimization Playbook (Amazon.ca)

How to write the title, bullets, description, and backend keywords for each ASIN. Fill the
working copy in `04_Listing-Copy/listing-copy.md` (from `02_Templates/02_listing-copy-template.md`).

**Rule:** Every claim traces to the spec sheet, label, official site, or live listing. When in
doubt, cut it. Food listings on Amazon.ca must also respect Canadian labelling law (see `07`).

---

## 1. Title
**Formula:** `Brand + Product Line + Key Attribute + Format/Variant + Net Quantity (metric first)`

- Front-load the brand (**Atwood Heritage**) and the most-searched product noun.
- Include the primary keyword naturally within the first ~80 characters.
- Include **net quantity in metric** (g/kg/mL/L) — required in Canada; imperial may follow in parentheses.
- Target ≤ 200 characters; aim for 120–150 for mobile readability.
- Title case. No ALL-CAPS words, no promotional text ("Sale", "Best"), no emojis, no seller name.
- No unverified claims ("healthiest", "#1").

**Template:**
`Atwood Heritage [Product] – [Key Attribute], [Format/Variant] – [NetQty g/mL] ([count] pack)`

**Example shape (fill with real facts):**
`Atwood Heritage Maple Breakfast Granola – Small-Batch, Whole Grain Oats – 500 g`

---

## 2. Bullet points (5)
One benefit per bullet, benefit-led, fact-backed. ~150–220 chars each.

Recommended slot pattern:
1. **Headline benefit / what it is** — lead with the strongest verified attribute.
2. **Ingredient / quality / sourcing** — provenance, key ingredients (from label).
3. **Taste / experience / format** — texture, flavour notes, format (whole bean, ground, etc.).
4. **Practical / usage / servings** — how to use, servings per pack, storage.
5. **Brand trust / dietary flags** — heritage line + any *certified* dietary attributes (gluten-free, non-GMO, kosher) ONLY if held.

Style:
- Start each bullet with a short **BOLDED LEAD-IN** (2–4 words) then the detail.
- No medical/health-outcome claims. No competitor bashing.
- Keep dietary claims to verified certifications; otherwise describe factually ("no artificial colours" only if true per label).

---

## 3. Product description / A+ fallback
- If A+ Content is published, the description field is often hidden — still fill it for safety and non-A+ surfaces.
- 1–3 short paragraphs: the heritage story + the product + how to enjoy it.
- Plain, warm, premium tone. No claims beyond the spec.
- Include secondary keywords naturally.

---

## 4. Backend search terms (keywords)
- Use the **Search Terms** field (~250 bytes on Amazon). Do not repeat words already in the title (wasteful).
- No brand names of competitors, no ASINs, no profanity, no "cheap/sale" spam.
- Include: synonyms, use-cases, occasions, French-language terms (Amazon.ca is bilingual), common misspellings sparingly.
- Lowercase, space-separated, no commas needed, no quotation marks.

**Keyword sources:**
- Product category + synonyms (e.g. granola, cereal, breakfast, muesli).
- Attributes (whole grain, small batch, Canadian).
- Occasions/use cases (breakfast, snack, hiking, gift).
- **French equivalents** (granola, céréales, grains entiers, canadien) — important for `.ca`.

---

## 5. Category, subject matter & attributes
- Choose the most specific browse node (Grocery > ... > correct leaf).
- Fill all applicable structured attributes (net weight, unit count, allergens, dietary, ingredients, storage, country of origin). Complete attributes improve indexing and reduce suppression.
- Provide **bilingual** content where the field supports it.

---

## 6. Optimization checklist (per ASIN)
- [ ] Primary keyword in first 80 chars of title
- [ ] Metric net quantity in title
- [ ] 5 bullets, benefit-led, fact-backed, bolded lead-ins
- [ ] No prohibited/medical/unverified claims
- [ ] Description filled (heritage + product + usage)
- [ ] Backend keywords: no title-word repeats, includes FR terms
- [ ] All structured attributes completed (allergens, origin, dietary)
- [ ] Every claim logged with source in QA sheet
