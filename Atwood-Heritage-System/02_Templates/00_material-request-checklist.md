# Brand Material Request Checklist — per ASIN

Send this to the brand before starting an ASIN. Anything not supplied → cannot appear in the
listing. Mark each item ✅ received / ⚠️ pending / ❌ n/a.

**ASIN:** ______   **Product:** ______   **Requested:** ______   **Owner:** ______

---

## 1. Identifiers & listing
- [ ] Amazon.ca ASIN + listing URL
- [ ] Product title / official product name
- [ ] Brand name lockup as it should appear
- [ ] Variant / flavour / size relationships (parent-child)

## 2. Product specs
- [ ] Net quantity (metric: g/kg/mL/L) + count per pack
- [ ] Servings per container + serving size
- [ ] Format (whole bean/ground, whole/sliced, etc.)
- [ ] Dimensions & weight of pack (for size callouts)
- [ ] Storage conditions + shelf life / expiry handling
- [ ] Prep / usage instructions
- [ ] Country of origin + exact origin claim wording ("Product of Canada" vs "Made in Canada")

## 3. Label & regulatory
- [ ] **Front-of-pack** label image (high-res)
- [ ] **Nutrition Facts** table image (bilingual EN/FR, high-res, legible)
- [ ] **Ingredient list** image/text (exact order)
- [ ] **Allergen statement** ("Contains:")
- [ ] Any certifications held + **logo files + proof/certificate** (organic, non-GMO, gluten-free, kosher, halal…)
- [ ] Substantiation for any nutrient/compositional claim to be used

## 4. Photography (raw)
- [ ] Front product/pack photo — high-res, clean
- [ ] Back + sides of pack
- [ ] Product-out-of-pack / contents shot
- [ ] Ingredient / raw-material shots (beans, grain, fruit, etc.)
- [ ] Lifestyle / in-use photos (if any brand-approved exist)
- [ ] Product range / line-up photos
- [ ] All at ≥ 2000 px, uncompressed if possible

## 5. Brand assets
- [ ] Logo (vector SVG/EPS/AI + transparent PNG)
- [ ] Brand colors (hex/CMYK) + fonts (files or names)
- [ ] Brand guidelines doc (if any)
- [ ] Approved heritage/brand story copy (founding year, region, family-owned, values) — **written confirmation**
- [ ] Approved marketing claims list / do-not-say list
- [ ] Official website URL

## 6. Approvals
- [ ] Who signs off final listing?
- [ ] Any legal/regulatory review required before publish?
